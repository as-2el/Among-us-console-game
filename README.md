🎮 Among Us Console Game

A simple console-based Among Us inspired game built with C#.
The player explores different rooms, finds clues, and tries to discover who the imposter is before the game ends.

_____________________________________________________
✨ Features

Console-based gameplay

Randomly selected imposter and victim

Interactive levels with clues

Voting system

ASCII art interface

Supports 5–10 players

_____________________________________________________
🕹️ How the Game Works

1. The player enters the number of players.


2. All player names are entered.


3. The game randomly chooses:

One imposter

One victim



4. The player explores different rooms:

Power Room

Security Room

Storing Room



5. Clues are discovered through the investigation.


6. At the end, players vote for who they think the imposter is.



If the correct imposter is chosen → Victory 🎉
Otherwise → Game Over 💀

_____________________________________________________
🧩 Levels

Level 1 — Power Room

Level 2 — Security Room

Level 3 — Storing Room
